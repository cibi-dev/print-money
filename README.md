**Profit, expense, and net income manager for a 3D printing business.**

A sleek desktop application built with Python and CustomTkinter to help small 3D printing businesses track orders, manage expenses, monitor inventory, and generate professional invoices — all from a single dashboard.


## Download

Get the latest Windows build from the [Releases page](https://github.com/cibi-dev/print-money/releases).

1. Download the latest .zip file (e.g. PrintMoney-Windows.zip) from the [releases](https://github.com/cibi-dev/print-money/releases/latest).
2. Extract the entire folder to a location of your choice (e.g. Desktop or C:\Apps\PrintMoney\).
3. Run PrintMoney.exe from the extracted folder.
4. **Windows SmartScreen:** If you see Windows protected your PC, click More info → Run anyway. This is common for unsigned applications.

> Note: The app stores all data locally at %APPDATA%\PrintMoney\. You don't need to install Python to run the packaged .exe.
